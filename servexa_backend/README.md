# Servexa Frontend

This repository contains all the necessary files to support the backend of the Servexa web-application.

## Overview

This project is a web application that helps users track maintenance requests, vendors, and tenants on a fictional campus.

## Features

- User authentication
- Real-time updates
- Responsive design
- REST API integration
